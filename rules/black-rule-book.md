# 附录A · 黑棋完整规则书(机器验证版)
**使用方法**

1. 轮到黑方时, 先把**你的黑子形状**与本书的形状图对照(●=黑子; 白子位置不看图, 看条件)。
   若你的形状在书中没有, 但**左右镜像**后有, 则查镜像条目, 并把查到的走法**左右镜像**后执行(列 c 变 5−c, 行不变)。
2. 找到形状条目后, **从上往下**逐条尝试:
   - "若[条件]"行: 条件全部成立就走该走法(条件只涉及白子位置, 一眼可查);
   - "候选"行: 该走法**合法**(起点有己子、终点空)且走完后你的新形状仍在本书形状表中, 就走它; 否则看下一条。
   - 第一条命中的立即执行, 不再看后面。
3. 吃子规则(强制)按原规则执行; 若一步同时有横竖两个吃子候选, **吃行号更大的那个**(即更靠下、离你更近的那个)。
4. 黑子始终不离开 10 格区域 R = 第3行、第4行 + (2,2)、(2,3)。书中给出的走法自动满足这一点。

**保证**(穷举验证, 见验证报告): 黑按本书走, 白方**任意**走法都无法获胜;
对局要么黑胜, 要么按三次重复规则和棋。
